# Contributing to RoamSpin

Thanks for wanting to contribute! 🎡

## Development

```bash
npm install
npm run dev
```

Create a branch:

```bash
git checkout -b feat/my-feature
```

Before opening a PR:

```bash
npm run build
```

## Pull requests

Keep PRs focused and explain:

- What changed
- Why it changed
- How you tested it

For destination data, include reliable sources when possible and avoid unsupported precise prices or travel times.

## Good first contributions

- Add destinations
- Correct destination metadata
- Improve accessibility
- Improve responsive layouts
- Add tests
- Improve map behaviour
- Add game modes
- Improve documentation

Please do not commit:

- `.env.local`
- API keys
- `node_modules`
- `dist`
- personal location data
